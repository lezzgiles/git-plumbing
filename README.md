# git-plumbing


This repo contains a powerpoint presentation with labs that covers git plumbing.
It has grown (and will continue growing) to include more aspects of Git.
The goal of the training is to educate the user about the underlying
principles of Git, not to teach them day-to-day commands.  If you work
through this, you will be able to list the four object types stored in
Git, you'll be able to list the different standard types of reference and
you'll be able to explain just how merge conflicts are represented inside a
repo - all parts of Git plumbing - but you won't be able to list the 23
different uses of the git-checkout command - which is part of Got porcelain.

The course was originally presented as a two-day in-person course at various
companies.  I am happy to make myself available to present it for you or
your company, for a fee (of course).  I can be reached through LinkedIn using
the name "Lezz Giles".
